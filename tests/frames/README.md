# Reference Frames

13 reference frames for the C1-Slim e-paper format, 5624 bytes each. They are
deliberately chosen so that a decoder which misreads the layout (bit order, strip
boundary, row width, offset formula) will disagree on at least one of them.

The format is specified in [`../../FRAME-FORMAT.md`](../../FRAME-FORMAT.md); the
authoritative implementation is `src/display/frame.c`.

## Catalog

Each file targets one class of format error:

| File | Content | Catches |
|---|---|---|
| `all_white.bin` | all bits 0 | bit polarity inverted |
| `all_black.bin` | all bits 1 | bit polarity inverted |
| `row0.bin` | only row 0 black | bit order (MSB/LSB) at the top edge |
| `row7.bin` | only row 7 black | last row of strip 0 (MSB/LSB) |
| `row8.bin` | only row 8 black | first row of strip 1 (strip boundary) |
| `row151.bin` | only row 151 black | bottom edge (`152 = 19 × 8`, no partial strip) |
| `col0.bin` | only column 0 black | row width taken from the wrong constant |
| `col295.bin` | only column 295 black | row width taken from the wrong constant |
| `corners.bin` | the four corners | all four corners together |
| `checker1.bin` | 1×1 checkerboard | offset formula, row/column transposition |
| `checker8.bin` | 8×8 block checkerboard | strip index `y/8` vs `y%8` |
| `bits.bin` | `f[i] = byte(i)` | all 8 bit positions across every byte |
| `random.bin` | fixed-seed PRNG content | general regression pressure |

## Verifying

`verify.py` is a standalone checker (no dependencies). It re-derives each frame from
the documented layout with its own `set_pixel()` routine and compares byte-for-byte,
so a mismatch means the layout or the file is wrong:

```sh
python3 tests/frames/verify.py
```

It exits non-zero on any mismatch. The equivalent decode in one line:

```python
W, STRIP = 296, 8
pixel = lambda f, x, y: (f[(y // STRIP) * W + x] >> (7 - (y % STRIP))) & 1  # 1 = black
```

## Provenance

These vectors are generated by
[`c1slim-sim`](https://github.com/Soidea/c1slim-sim) (GPL-3.0) with a small
deterministic generator, and were cross-checked to decode identically under two
independent implementations (a Go decoder and the MIT-licensed `frame2png.py`). They
are plain data conforming to the format this repository already implements; no code
from this repository is included.
